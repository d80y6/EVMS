# DAM VMS: Next-Generation Distributed Video Management System

DAM VMS is a high-performance, enterprise-grade, and AI-native VMS platform.

## Key Features
- **Cloud-Native Architecture:** Built for Kubernetes and microservices.
- **AI-First:** Native integration of object detection and tracking with distributed worker pools.
- **Low Latency:** WebRTC-based live streaming.
- **Enterprise Ready:** Multi-tenancy, RBAC, and comprehensive audit logs.
- **Scalable Storage:** Support for tiered storage from local NVMe to S3.
